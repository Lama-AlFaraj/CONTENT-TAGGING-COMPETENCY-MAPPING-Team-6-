Content Tagging & Competency Mapping — Evaluation UI

Send one piece of learning content to one or more model endpoints and compare the structured output side by side. Runs entirely in your browser — nothing is sent anywhere except the endpoints you configure below.

1. Endpoints

Default field expects a BeamData-style API exposing POST {base_url}/predict with a multipart file field, returning JSON with predicted_tags, proposed_competencies, difficulty_level, confidence, notes. The base URL must be reachable from your browser and allow CORS from this page's origin.

Supported: .pptx, .ipynb, .xlsx, .md, .txt, .csv
